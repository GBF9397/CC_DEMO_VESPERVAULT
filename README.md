### How to play

| | Phone | PC |
|---|---|---|
| Walk | Drag on the left side (joystick) | W A S D or arrow keys |
| Use / pick up / talk | Round button, bottom right | E |
| Quest, bag, map | Pause button, top right | Q, I, M |

- Phone: hold it **sideways**. First load takes a few seconds (about 6 MB), then it is cached.
- Add to home screen (Safari: Share > Add to Home Screen) to open it like an app.
